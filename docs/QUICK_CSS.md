# Quick CSS: справочник NexLauncher

## 1. Что это

Quick CSS — небольшой CSS-подобный язык для внешнего вида NexLauncher. Файл читается как текст, проверяется и преобразуется в ограниченный набор стилей Avalonia. Браузер, JavaScript, произвольный XAML и полный CSS-движок здесь не используются.

Стиль накладывается поверх стандартной темы. Отключение Quick CSS удаляет этот слой и возвращает исходное оформление. Настройки сборок, запуск игры и авторизация от темы не зависят.

Организация примера — отдельные переменные, поверхности, типографика и состояния — вдохновлена [структурой тем ClearVision](https://clearvision.github.io/ClearVision-v7/main.css). CSS ClearVision предназначен для другого приложения и **не совместим** с NexLauncher; импортировать его вместо примера нельзя.

## 2. Как включить

Открой **Настройки → Quick CSS**. По умолчанию Quick CSS выключен.

Самый быстрый старт — **Создать пример**: лаунчер копирует [Plum Evening](../Assets/quickcss.example.css) в папку данных, выбирает файл, включает Quick CSS, сохраняет настройки и сразу применяет тему. Уже существующий файл не перезаписывается: для новой копии используется уникальное имя.

Или нажми **Выбрать файл**, выбери свой `.css`, отметь **Включить Quick CSS** и нажми **Применить**. Изменения флажков и пути действуют после **Применить** или **Перезагрузить**. Чтобы вернуть стандартный вид, сними флажок включения и примени изменения.

## 3. Где находится файл

Пример создаётся в `<папка данных NexLauncher>/themes/quickcss.css`. На Windows обычный путь — `%LOCALAPPDATA%\NexLauncher\themes\quickcss.css`; точная папка данных показана в настройках приложения. Для повторной копии к имени добавляются дата и уникальный идентификатор.

Можно выбрать любой существующий локальный файл `.css` через диалог выбора или указать его полный путь. **Открыть в редакторе** запускает редактор, назначенный в ОС для `.css`. Если вместо редактора открывается другое приложение, измени файловую ассоциацию в системе или открой файл через редактор вручную.

Файл должен быть в UTF-8; UTF-8 BOM допустим. Путь, флаги включения и автообновления сохраняются в существующем `settings.json`, в объекте `QuickCss` (`Enabled`, `FilePath`, `AutoReload`). Сам текст темы остаётся в `.css`.

## 4. Ручная перезагрузка

Сохрани CSS в редакторе и нажми **Перезагрузить**. Перезапуск NexLauncher не нужен. Эта кнопка также сохраняет текущие значения пути и флажков в настройках перед применением.

Изменение файла на диске не происходит от нажатия **Применить**: сначала сохрани его в редакторе.

## 5. Автоматическое обновление

При включённом **Автообновлении** лаунчер следит за выбранным CSS-файлом через `FileSystemWatcher`. Серия уведомлений объединяется с задержкой 300 мс. Поддерживаются обычная запись и сохранение через временный файл с последующим переименованием.

Чтение, синтаксический разбор и подготовка фоновых изображений выполняются вне UI-потока; установка стилей выполняется на UI-потоке Avalonia. Новая загрузка отменяет устаревшую. Наблюдатель и ресурсы освобождаются при смене файла и закрытии окна.

Изменения **изображений** отдельно не отслеживаются. После изменения картинки сохрани CSS ещё раз или нажми **Перезагрузить**. Если наблюдение недоступно, интерфейс покажет замечание, а ручная перезагрузка останется доступной.

## 6. Базовый синтаксис

```css
/* Комментарий */
.card, #account-panel {
    background-color: #30263e;
    border-radius: 16px;
    padding: 12px 18px;
}
```

Правило состоит из селектора или списка через запятую и блока `{ ... }`. Декларация записывается как `свойство: значение;`. Последнюю точку с запятой перед `}` можно опустить, но лучше писать её везде. Поддерживаются многострочные комментарии `/* ... */`; комментарии `//` не поддерживаются.

Имена свойств нечувствительны к регистру. Имена селекторов и переменных чувствительны: используй `button`, а не `Button`. Пробелы допустимы вокруг разделителей, но не создают связи между элементами: `.card button` не поддерживается.

Порядок правил сохраняется: последнее подходящее активное правило выигрывает для заданного свойства. Внутри одного правила последняя декларация одного свойства также выигрывает. Общее оформление удобно задавать сначала, специальные элементы и состояния — затем. Браузерный подсчёт специфичности и каскадные слои не реализуются; доступность состояний определяется Avalonia.

## 7. Все доступные селекторы

Ниже перечислен публичный набор. Произвольные имена контролов, `x:Name` и внутренние классы Avalonia недоступны.

| Селектор или равнозначные варианты | Элемент / категория |
| --- | --- |
| `:root`, `window`, `#app` | Главное окно, корневое оформление |
| `button` | Все кнопки |
| `textbox`, `.input` | Поля ввода, включая журнал |
| `combobox` | Выпадающие списки |
| `list-item` | Строки списков сборок, управляемых модов и результатов Modrinth (`ListBoxItem`) |
| `text` | Текстовые блоки |
| `.card` | Карточки с содержимым |
| `.primary`, `.button-primary` | Основные кнопки действий |
| `.nav`, `.navigation-item` | Кнопки боковой навигации |
| `.nav.active`, `.nav.selected`, `.navigation-item.selected` | Активная кнопка навигации |
| `.title` | Заголовки страниц |
| `.muted`, `.text-muted` | Приглушённый текст |
| `.caption` | Подписи и пояснения |
| `.quiet` | Второстепенные текстовые кнопки |
| `#sidebar` | Фон боковой панели, рамка |
| `#content` | Основная область содержимого, панель |
| `#play-button` | Кнопка установки / запуска выбранной сборки |
| `#instance-card` | Карточка выбранной сборки на странице игры |
| `#account-panel` | Панель аккаунта в верхней части окна |
| `#log-panel` | Карточка журнала запуска |

Список расширяется в `Services/QuickCss/QuickCssSelectorCatalog.cs`. Синтаксический парсер отделён от этого списка: неизвестный, но синтаксически корректный селектор даёт замечание на этапе применения.

Modrinth search/details и установка loaders используют тот же набор: `.card`,
`button`, `.primary`, `.quiet`, `text`, `.caption`, `.muted`, `textbox`, `combobox`,
`list-item`. Новые специальные selectors не требуются. Описание проекта рендерится
нативными текстовыми блоками, а ссылки — `.quiet` кнопками. Код внутри описания
имеет моноширинный шрифт; HTML проекта не может добавлять свои стили или selectors.

## 8. Все поддерживаемые свойства

Числа записываются через точку, независимо от языка Windows. Размеры используют `px` или число без единицы. `px` здесь соответствует логической единице Avalonia; системный масштаб DPI продолжает работать.

| Свойство | Значение и диапазон | Где применяется |
| --- | --- | --- |
| `background`, `background-color` | Цвет; обе записи равнозначны | Все селекторы из таблицы |
| `color` | Цвет текста / наследуемый цвет | Все; дочерний элемент может иметь собственный цвет |
| `accent-color` | Цвет основных акцентов темы | Только `:root`, `window`, `#app` |
| `border-color` | Цвет рамки | Окно, кнопки, поля, выпадающие списки, list-item, карточки и панели-рамки |
| `border-width` | 1–4 размера, каждый 0–20 | Те же элементы с рамкой |
| `border-radius` | 1–4 размера, каждый 0–100 | Те же элементы с рамкой |
| `font-size` | Число / `px`, 8–96 | Все; действует на текст и через наследование |
| `font-weight` | `normal` = 400, `bold` = 700, либо 100, 200, …, 900 | Все; действует на текст |
| `font-family` | Одно имя установленного системного шрифта, например `"Segoe UI"` | Все; действует на текст и через наследование |
| `opacity` | Число 0–1 | Все; прозрачность всего элемента вместе с детьми |
| `padding` | 1–4 размера, каждый 0–200 | Все, кроме `#content` |
| `margin` | 1–4 размера, каждый 0–200 | Все |
| `background-image` | `url("images/background.png")` либо `none` | Все селекторы с фоном |
| `background-size` | `cover`, `contain`, `stretch` | В том же правиле, где `background-image` |
| `background-position` | `center`, `top`, `bottom`, `left`, `right` | В том же правиле, где `background-image` |
| `background-opacity` | Число 0–1 | В том же правиле, где `background-image`; прозрачность только изображения |

`#content` — обычная панель Avalonia: `padding`, `border-color`, `border-width` и `border-radius` для неё не поддерживаются. Текстовые селекторы (`text`, `.title`, `.muted`, `.text-muted`, `.caption`) поддерживают `padding`, но не свойства рамки. Все карточки, `#sidebar`, `#instance-card`, `#account-panel`, `#log-panel` являются панелями-рамками и поддерживают эти свойства.

Для `padding`, `margin`, `border-width` порядок обычный CSS:

```css
.card {
    padding: 16px;              /* все стороны */
    padding: 12px 20px;         /* верх/низ, право/лево */
    padding: 12px 20px 16px;    /* верх, право/лево, низ */
    padding: 8px 12px 16px 20px; /* верх, право, низ, лево */
}
```

У `border-radius` четыре позиции — верхний левый, верхний правый, нижний правый, нижний левый угол. Формы с 1–3 значениями расширяются аналогично CSS. Эллиптические радиусы через `/` не поддерживаются. Отрицательные размеры не поддерживаются, включая `margin`.

`font-family` проверяется по установленным шрифтам. Допустимы буквы, цифры, пробел, `-`, `_` и необязательные кавычки вокруг имени. Списки fallback, URI и загрузка шрифтов из файла/сети не поддерживаются. Отсутствующий шрифт даёт замечание и не меняет стандартный шрифт. Наследуемые `color` и параметры текста не перекрывают собственное оформление каждого дочернего элемента; используй нужный текстовый селектор для точного изменения.

## 9. Переменные

Объявляй переменные только в **отдельном** правиле `:root`:

```css
:root {
    --main-color: #edaac8;
    --hover-color: #ffd0e2;
    --surface-color: #30263e;
    --roundness: 14px;
    --text-size: 14px;
    accent-color: var(--main-color);
}
.primary {
    background-color: var(--main-color);
    border-radius: var(--roundness);
}
.primary:hover {
    background-color: var(--hover-color);
}
```

Имена произвольные: `--main-color` не является встроенной командой или ключом Avalonia. Переменная что-либо меняет только там, где используется `var(--main-color)`. Переменные могут содержать цвет, размер, строку шрифта, путь `url(...)` или другое поддерживаемое значение свойства.

Переменные глобальные для файла. Последнее объявление в `:root` выигрывает во всём документе, даже в расположенных выше правилах. Вложенной области видимости и наследования переменных нет. Объявления в `window`, `#app`, `:root, button` и других правилах игнорируются с замечанием.

Поддерживаются ссылки на другие переменные и запасное значение:

```css
:root {
    --surface: #30263e;
    --card-background: var(--surface);
}
.card {
    background-color: var(--card-background, #26292d);
    border-color: var(--missing, rgba(255, 255, 255, 0.2));
    color: var(--missing, var(--also-missing, #ffffff));
}
```

Циклические переменные недействительны. Использующая их декларация пропускается; внешний `var(--cyclic, fallback)` может дать корректный запасной вариант. Текст внутри кавычек не раскрывается: `"var(--font)"` — буквальная строка. Используй `font-family: var(--font);`, если сама переменная содержит `"Segoe UI"`.

## 10. Цвета

Поддерживаются:

| Запись | Пример / смысл |
| --- | --- |
| `#RGB` | `#8af` → `#88aaff` |
| `#RGBA` | `#1234` → R=17, G=34, B=51, A=68 |
| `#RRGGBB` | `#edaac8` |
| `#RRGGBBAA` | `#edaac880` — альфа последняя, как в CSS |
| `rgb(r, g, b)` | `rgb(237, 170, 200)`, целые каналы 0–255 |
| `rgba(r, g, b, a)` | `rgba(237, 170, 200, 0.5)`, альфа 0–1 |
| Имена | `transparent`, `black`, `white`, `red`, `green`, `blue`, `gray`, `grey` |

Регистр имён и функций цвета не важен. `green` означает стандартный CSS-цвет `#008000`. Не используй XAML-порядок `#AARRGGBB`: здесь альфа всегда **в конце**. Проценты в цветовых каналах, `hsl()`, новые формы `rgb(1 2 3 / .5)`, `currentColor` и остальные названия цветов пока не поддерживаются.

## 11. Фоновые изображения

```css
#content {
    background-image: url("images/forest.jpg");
    background-size: cover;
    background-position: center;
    background-opacity: 0.2;
}
```

Путь считается **от папки выбранного CSS**, например `themes/images/forest.jpg`. Разрешены только локальные PNG, JPG, JPEG внутри этой папки и её обычных подпапок. Используй `/` как разделитель для переносимости.

Не допускаются HTTP(S), `data:`, `file:`, абсолютные и сетевые пути, сегменты `.`/`..`, символические ссылки и Windows reparse points. Лаунчер не скачивает картинки по URL. Максимум четыре разных изображения на тему; каждое до 8 МиБ и до 4096 пикселей по каждой стороне, суммарно до 16 777 216 пикселей.

`cover` заполняет область с сохранением пропорций и обрезкой; `contain` вмещает изображение целиком; `stretch` растягивает без сохранения пропорций. По умолчанию используется `cover` и `center`. Позиция задаётся одним словом; комбинации вроде `left top` не поддерживаются.

Изображение заменяет кисть фона элемента. Несколько слоёв, смешивание с `background-color`, повторение, blur, фильтры, градиенты и анимация не реализованы. Если задать цвет и изображение для одного элемента, последнее применимое объявление фона выигрывает. `background-image: none` задаёт прозрачный фон; оно не восстанавливает предыдущий цвет автоматически. Для цветного фона укажи `background-color`.

Настройки размера, позиции и прозрачности картинки нужно писать **в том же правиле**, что и `background-image`; отдельно они не накапливаются. `background-opacity` влияет только на кисть изображения, `opacity` — на весь элемент и детей.

## 12. Состояния элементов

После поддерживаемого селектора можно указать одно состояние:

| Состояние | Где доступно | Значение |
| --- | --- | --- |
| `:hover` | Кнопки, поля ввода, выпадающие списки, list-item и их именованные варианты | Указатель находится над элементом |
| `:disabled` | Те же элементы | Элемент недоступен для взаимодействия |
| `:selected` | `.nav`, `.navigation-item`, `list-item` | Активная страница навигации или выбранная сборка в списке |

```css
.primary:hover { background-color: #ffd0e2; }
.primary:disabled { background-color: #3c3046; color: #a596af; }
.input:hover { border-color: #edaac8; }
.nav:selected { background-color: #563653; color: #ffd0e2; }
list-item:selected { background-color: #563653; border-color: #edaac8; }
```

`.nav.active`, `.nav.selected` и `.navigation-item.selected` — также готовые селекторы выбранного пункта навигации. `:hover` переводится в Avalonia `:pointerover`; `:disabled` использует состояние Avalonia, `:selected` навигации — существующий признак активной страницы, а у `list-item` — состояние выбранной строки Avalonia.

Для карточек, текстов и корневого окна состояния не поддерживаются. Несколько псевдосостояний подряд (`button:hover:disabled`), `:focus`, `:pressed`, псевдоэлементы и произвольные состояния не реализованы. Пиши правила состояний после обычных правил, чтобы тему было проще читать.

## 13. Отличия от браузерного CSS

Quick CSS меняет оформление существующих контролов; он не перестраивает интерфейс и не заменяет стандартную тему целиком.

Не поддерживаются `@import`, `@media`, `@font-face`, `@keyframes`, `!important`, вложенные правила, произвольные классы, комбинаторы (`>`, `+`, `~`, пробел), селекторы атрибутов, `*`, CSS Grid/Flex, `display`, `position`, `width`/`height`, `z-index`, `calc()`, `em`/`rem`/`%`/viewport-единицы и браузерные шорткаты вроде `border: 1px solid red`. Для рамки используй отдельные свойства.

`background` здесь является только синонимом `background-color`; он не разбирает сложный CSS-шорткат. Отсутствуют эффекты, переходы, скрипты, сетевые ресурсы и произвольные Avalonia bindings. Сам файл не может выполнять код.

Ограничения разбора: 128 КиБ UTF-8, максимум 256 правил и 2048 деклараций; до 4096 символов на исходное и раскрытое значение; до 32 уровней круглых скобок и до 16 уровней ссылок переменных. Работа по раскрытию переменных дополнительно ограничена общим бюджетом. Все эти пределы нужны для предсказуемой загрузки темы.

## 14. Ошибки и восстановление

В блоке Quick CSS отображаются статус и замечания с номерами строк. Показываются первые 12 замечаний и количество остальных. Строка `0` означает общую ошибку файла или наблюдателя, а не конкретное CSS-правило.

Некорректная декларация пропускается; соседние корректные продолжают работать. Неизвестное свойство или селектор также даёт замечание. Вложенный или незакрытый блок пропускается целиком; ошибка фигурных скобок может затронуть следующий текст, поэтому сначала исправляй скобки. При синтаксических ошибках применяется корректная часть нового файла, а не смесь с предыдущей темой.

Если файл не удаётся прочитать, декодировать как UTF-8 или он слишком большой, последний применённый стиль сохраняется. После исправления нажми **Перезагрузить**. Неверный путь к фоновому изображению не мешает остальным свойствам темы. Ошибки не должны закрывать лаунчер; отключение Quick CSS всегда возвращает стандартные стили.

## 15. Короткие примеры

**Заменить акцент и главную кнопку:**

```css
:root { --accent: #bb9af7; accent-color: var(--accent); }
.primary { background-color: var(--accent); color: #211b30; }
.primary:hover { background-color: #d8c5ff; }
```

**Изменить карточки:**

```css
.card {
```

## 16. Полный пример и расширение реализации

[Assets/quickcss.example.css — Plum Evening](../Assets/quickcss.example.css) содержит готовую заметно отличающуюся тему: сливовые поверхности, розовый акцент, тёплый текст, скругления, оформление кнопок/полей/навигации, состояния наведения/выбора/недоступности и закомментированный пример локального фона. Для проверки без дополнительных файлов достаточно **Создать пример**.

В примере сначала меняй переменные в `:root`, затем отдельные правила. Изображение и системный шрифт оставлены необязательными: тема работает без установки шрифтов и скачивания картинок.

Для разработчиков ответственности разделены: `QuickCssParser` разбирает синтаксис и переменные; `CssValueParser` проверяет чистые значения; `QuickCssSelectorCatalog` определяет публичные цели; `QuickCssStyleApplier` создаёт разрешённые Avalonia setters и управляет временным слоем; отдельный загрузчик изображений проверяет пути, размеры и декодирует фоны; `QuickCssService` отвечает за чтение, перезагрузку и наблюдение; `QuickCssViewModel` интегрирует настройки и сообщения. Новый селектор или свойство добавляется в каталог / отображение свойств, без переписывания синтаксического парсера.
