NexLauncher — конфиденциальность и обработка данных
Дата: 20 октября 2026

Эта информация описывает текущую desktop-версию NexLauncher. Это уведомление,
а не согласие на отправку данных или принятие условий сторонних API.

Локальные данные

Настройки, список сборок, сведения об аккаунтах, темы Quick CSS и библиотека
скинов хранятся в папке данных NexLauncher. В Windows по умолчанию это
%LOCALAPPDATA%\NexLauncher, на macOS — ~/Library/Application Support/NexLauncher,
на Linux — $XDG_DATA_HOME/NexLauncher (обычно ~/.local/share/NexLauncher).
Игровые папки могут находиться в выбранном пользователем
месте. Реальные пути показаны в настройках.

Microsoft authentication использует существующий вход через Microsoft/Xbox/
Minecraft Services. На Windows используется прежнее окно WebView2 и DPAPI.
На macOS/Linux browser backend требует зарегистрированный Client ID владельца
(в текущем preview он не настроен). Его token cache защищён AES-256-GCM;
ключ хранится в Keychain/Secret Service через Microsoft MSAL persistence provider.
При недоступном системном хранилище открытое хранение токенов не используется.
Браузерная сессия Microsoft хранится самим системным браузером. Local/Offline
профили хранятся отдельно и не подтверждают владение Minecraft. NexLauncher не
выдаёт локальный профиль за Microsoft-аккаунт и не отключает проверку серверов.

Скины Offline и локальная библиотека PNG остаются на устройстве. Применение
Microsoft-скина отправляет выбранное изображение в Minecraft Services только
после действия пользователя. Local Skin не становится общедоступным игровым скином.

NexStats хранит историю сессий и, при включённом мониторинге, RAM/CPU samples.
NexDoctor анализирует логи и crash reports локально. В них могут встречаться имена,
пути, адреса серверов и сведения о системе. Автоматической облачной отправки
диагностики, обязательного AI-сервиса и скрытой установки client mods нет.

Сетевые обращения

Для установки/repair игра, Java и загрузчики скачиваются с предусмотренных
официальных источников. Каталог Modrinth получает поисковую строку, выбранные
фильтры, Minecraft version, loader и project/version IDs. Нужные файлы загружаются
с разрешённых CDN/источников. Microsoft tokens не используются для Modrinth.

Вход Microsoft и операции со скином обращаются к соответствующим сервисам
Microsoft/Minecraft. Сервис, к которому обращается приложение, видит IP-адрес
соединения и обычные HTTP metadata; запросы загрузчика идентифицируют NexLauncher.
Local/Offline account не означает, что загрузки и каталог работают без интернета.

Quick CSS может содержать HTTPS-ссылку на фоновое изображение. При применении
такой темы запрос уйдёт к указанному ресурсу. Проверка синтаксиса при наборе текста
не скачивает фон. Используй доверенные темы и проверяй их внешние ссылки.

В этой версии нет подключённого CurseForge API. Его внедрение требует отдельного
согласования доступа и правил обработки данных. Заявки/API terms не отправляются
и не принимаются лаунчером автоматически.

Экспорт и внешние ссылки

Экспорт сборки, статистики и PNG выполняется локально в выбранный файл. Перед
ручной передачей проверь содержимое. Configs, логи и crash reports могут содержать
личные данные; подтверждение прав на файлы не является проверкой их лицензий.

Внешние ссылки открываются по действию пользователя в обычном браузере.
Сторонние сайты применяют собственные правила конфиденциальности. В этой версии
нет встроенного приёма платежей. Возможная будущая ссылка на добровольную поддержку
разработки будет отдельной от поддержки авторов модов.

Удаление и управление

Аккаунт можно удалить из списка аккаунтов; локальные PNG — из библиотеки скинов.
Историю статистики/диагностики можно очистить в настройках с подтверждением.
Повреждённые исходные данные могут сохраняться для восстановления. Удаление записи
не отзывает ранее выданные стороннему сервису разрешения и не удаляет его данные.

Uninstall/обновление сохраняют пользовательские данные и custom instance folders.
Удаление игровых папок, журналов и оставшихся данных пользователь выполняет
отдельно. Не публикуй auth vault, settings, логи или архивы без предварительного
просмотра. Не добавляй credentials в текст issue.
